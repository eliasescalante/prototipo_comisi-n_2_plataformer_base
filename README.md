# Prototipo Plataformero Base

Este es un prototipo base para un juego de plataformas desarrollado en **Godot Engine**. El proyecto sirve como plantilla inicial con mecánicas de movimiento esenciales para juegos en 2D.

## 🚀 Características

* **Movimiento básico del jugador:** Caminar, correr y saltar (falta aplicar dash)
* **Detección de colisiones:** Configuración de capas y máscaras para suelo, plataformas y jugador.
* **Escenas organizadas:** Estructura limpia para fácil expansión de niveles y personajes.

## 🛠️ Requisitos Previos

* **Godot Engine 4.x** (recomendado para abrir e interactuar con el proyecto).
